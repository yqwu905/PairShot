配准工具

  1. 选择同一场景、有足够重叠纹理的两张照片。参考图决定结果的位置、尺寸和颜色。
  2. 优先使用 1024 px 查看效果；计算过程中可取消，已选照片会保留。
  3. 结果可在纯几何、全局调色和最终校正之间切换。双指缩放、拖动平移；视图旋转不改变导出的图片。
  4. 完成的结果保存在 App 内，可从历史结果重新打开，或导出 PNG、掩码和完整 ZIP。

结果怎么看

遮挡、反光、运动和缺乏纹理的区域可能无法可靠配准。掩码是质量筛选提示，并不保证每个像素都正确。颜色误差是当前图对拟合后的诊断。

增强颜色对齐使用参考图的低频颜色，也可能带入较大尺度的结构。严格训练数据可关闭此项，或使用“仅稠密几何”“几何 + 全局调色”结果。

手机本地计算

RootSIFT / MAGSAC 全局配准 → DIS 稠密光流 → 自适应全局颜色映射 → 带掩码的高斯低频颜色补偿。计算引擎随 App 安装，照片不上传。大图在导入时会受手机内存限制缩小；原始照片不会被修改。
